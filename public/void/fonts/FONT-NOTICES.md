# Website fonts

The public website uses the operating system's sans-serif fonts. The reference
site's Onest and unidentified Wordmark files are not required or redistributed
by the release: matching redistribution notices were not present in the local
reference assets.

The optional native control preview uses Monocraft, supplied by Idrees Hassan.
Its existing SIL Open Font License 1.1 and attribution are in
`LICENSE-Monocraft.txt` and `NOTICE-Monocraft.txt` beside the font.

No fonts are fetched from an external service.
