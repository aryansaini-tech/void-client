# Design resources and licensing

The brief's references were consulted during initial direction and again while designing the spotlight, showcase depth, magnetic controls and motion system. The result uses original local CSS/SVG and application code rather than imported website templates.

| Requested resource | Verified source and use |
| --- | --- |
| Flarial | https://flarial.xyz/ — reference for navigation, product presentation and community structure. No assets, branding, layout source or code were reused. |
| “Ceternity UI” | The supplied domain was unavailable. The relevant verified alternative was **Aceternity UI**, https://ui.aceternity.com/ with https://ui.aceternity.com/licence. Spotlight, container-scroll-animation and magnetic-button documentation informed the interaction direction. No Aceternity component source or paid asset was copied. |
| Animaster Library | https://animmasterlib.dev/ — reviewed the animation/component gallery for timing and presentation ideas. Paid-source redistribution rights were not established; no source code, assets or package was copied/installed. |
| Designer Prompts | The supplied `designerprompts.dev` address was unavailable. https://designprompts.dev/ and its terms were the verified alternative. Used as creative-direction guidance; no proprietary prompt library was redistributed. |

The external galleries were treated as design references, not assumed to be npm packages, MCP services or Next.js integrations. The actual implementation uses compatible installed Framer Motion/GSAP APIs and original components. Official Next.js, Better Auth, Stripe and Prisma documentation, installed type definitions and Context7 informed API choices.

Manrope is self-hosted through `@fontsource-variable/manrope` under its SIL Open Font License. Next.js, React, Tailwind, Framer Motion, Better Auth and Zod use their package licenses; Lucide uses ISC; Prisma uses Apache-2.0; GSAP uses its own standard license. Keep dependency license files with redistributed bundles and review the exact locked versions when changing distribution terms. No paid Aceternity or Animaster source is included.

The official V and wordmark are the user's supplied `assets/logo.png` and `assets/void-logo.png`; they are not redrawn or claimed as generated original logos. Zerix artwork also comes from the supplied assets. The voxel landscape, concept compositions and black/gold design system are original project work. Concept images are labelled because they are not verified client screenshots or gameplay captures. No unrelated stock gaming imagery is used.

During this visual upgrade, Aceternity's container-scroll reference, Animmaster's scroll/hover/text categories and DesignPrompts' dark/luxury direction were revisited. They informed bounded depth, stagger rhythm and restraint. All implementation remains local and original, using the already installed motion libraries; no paid source or additional animation dependency was introduced.
